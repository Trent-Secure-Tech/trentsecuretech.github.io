# Trent Secure Tech

**Privacy. Security. Control.**

A website for Trent Secure Tech, an independent technology service based in the East Midlands, focused on privacy-conscious mobile devices and GrapheneOS installation support.

## About

Trent Secure Tech aims to make privacy-focused technology more accessible through clear information and practical support.

The website provides information about:

* Privacy-focused Google Pixel devices
* GrapheneOS installation assistance
* Mobile privacy and security setup
* Available devices and contact information

## Website

The website is built using:

* HTML
* CSS
* SVG for the brand icon

It is designed with a dark background and green accents, with a responsive layout for desktop and mobile screens.
